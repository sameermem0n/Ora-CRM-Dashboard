## About OraCRM

OraCRM is a Customer Relationship Management system built with Laravel PHP framework.  
It helps businesses manage clients, services, packages, purchases, invoices, payments, and user roles from a centralized dashboard.  
Includes secure authentication, profile management, and role-based access control using Spatie Permission.

## Features
- Client & service management  
- Packages & purchases tracking  
- Invoice & payment records  
- User roles & permissions (Spatie)  
- Secure authentication & profile updates  

## Installation
1. Clone the repository  
2. Run `composer install`  
3. Configure `.env` file  
4. Run migrations: `php artisan migrate`  
5. Start server: `php artisan serve`
